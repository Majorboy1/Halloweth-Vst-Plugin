# Afrobeats kit sources

Halloweth's DRUMS page can load user-owned WAV samples onto the 16 pads and save
the result as a kit JSON file.

## Downloadable sources

- [LABADI: Afrobeats Drum and Percussion One-Shots](https://soundza.com/packs/afrobeats-drum-and-percussion-one-shots)
  currently lists 89 24-bit WAV sounds: kicks, snares, claps, hats, shakers,
  congas, bongos, shekere, agogo, woodblock, and stacked percussion hits.
- [Splice Afrobeats drum samples](https://splice.com/sounds/genres/afrobeat/drums/samples)
  is a larger paid catalog with licensed sounds for music production.

Download and unpack a kit, then use **DRUMS → LOAD SAMPLE** to assign the WAVs
you want and save the resulting kit. Halloweth does not bundle these packs: the
Soundza Standard License allows their use in finished music but prohibits
redistributing the sounds as a sample kit or other production library. Check the
terms for any pack before including its files in a product.
