# Emilyguitar samples

Recorded by D. Smolken on an Epiphone Emily the Strange electric guitar with flatwound strings. The upstream library contains 323 24-bit / 44.1 kHz WAV samples and multiple SFZ mappings for notes, noises, round robins, velocity layers, and chord voicings.

Source: https://github.com/sfzinstruments/karoryfer.emilyguitar
Instrument notes and download details: https://shop.karoryfer.com/pages/free-emilyguitar
License: CC0 1.0 Universal. The upstream LICENSE file is included in this folder.

The SFZ mappings are included from upstream with Windows path separators normalized to forward slashes. Halloweth's presets use `emily_basic.sfz` for melodic notes and `emily_chords.sfz` for chord voicings with keyswitches.
